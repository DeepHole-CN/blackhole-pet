黑洞宠物 · BlackHole Pet
=========================

安装
----
1. 把「黑洞宠物」拖进右边的 Applications（应用程序）文件夹
2. 打开「启动台」或「应用程序」，找到「黑洞宠物」，双击

第一次打开被系统拦住？
----------------------
因为这个 app 没有 Apple 开发者签名（签名要 99 美元/年），
macOS 会提示「无法打开，因为无法验证开发者」或者「已损坏」。

任选一种解决办法：

  方法一（推荐）
    在「应用程序」里找到它，**按住 Control 点一下**（或右键），
    选「打开」，再在弹窗里点一次「打开」。
    之后就能正常双击了。

  方法二（终端）
    打开「终端」，粘贴这一行回车：

      xattr -dr com.apple.quarantine "/Applications/黑洞宠物.app"

    然后再双击打开。

第一次运行的权限提示
--------------------
* 「屏幕录制」权限 —— **只有需要引力透镜（把桌面弯给黑洞看）时才需要**。
  不给也能正常用，只是看不到桌面被弯曲的效果。
  想开启：系统设置 → 隐私与安全性 → 屏幕录制 → 勾上「黑洞宠物」。

怎么玩
------
* 鼠标移到黑洞附近 → 出现状态面板
* 按住中间那团黑影拖动 → 把它拖到任何地方（只有黑影本体吃鼠标）
* 双击 → 打个嗝
* ⌥ + 滚轮 → 缩放体型
* 右键 → 全部设置
* ⌥⌘B → 喂食模式（把文件拖进去喂它）
* ⌥⌘H → 隐藏 / 显示

被吞掉的文件去哪了
------------------
默认**不会删除**，而是移进：~/BlackHolePet/eaten/
右键菜单 →「打开隔离区」可以随时捞回来。
每次操作都记在 ~/BlackHolePet/journal.jsonl。

只有把「吞噬方式」切成「永久删除」才会真删，这一项默认关闭。

卸载
----
  删除 /Applications/黑洞宠物.app
  删除 ~/BlackHolePet/                              （隔离区 + 流水账）
  删除 ~/Library/Application Support/黑洞宠物/       （设置）

系统要求
--------
macOS 11 或更高（Intel 和 Apple 芯片都支持）
